# 🧮 Calculadora Dark & Light Mode

Uma calculadora simples e estilizada com suporte a **modo claro, modo escuro e modo gradiente**!  
Feita com **HTML, CSS e JavaScript**, ideal para praticar manipulação do DOM e estilos dinâmicos.

![Calculadora](./img/calculator.png)

---

## 🚀 Funcionalidades

- ✅ Operações básicas: adição, subtração, multiplicação e divisão
- ✅ Botão CE (limpa tudo) e C (limpa o último número)
- ✅ Alternância entre **modo Light, Dark e Gradiente**
- ✅ Animações suaves e layout responsivo
- ✅ Design moderno com botões arredondados e sombras

---

## 🎨 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Puro)**
